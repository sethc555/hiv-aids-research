## The question P1 left open

P1 (static immunity) showed TIP efficacy collapses once a *fixed* immune killing
pressure is moderate. But a working TIP lowers viral load → lowers antigen →
should contract immunity → less killing → the TIP's production cells (dual-infected
`I_d`) survive. P1 omits that loop. **Does the TIP→antigen→immunity feedback open a
rescued regime the static model declared dead?** (de Boer static-pessimism vs
Pitchai 2024 live-immunity macaques.)

Model: immunity is now a dynamic effector `E(t)`, `dE/dt = a·E·A/(A+K_E) − d_E·E`
(antigen `A = I_w+I_d`); productive cells die at `d + k·E`. `a` = immune
responsiveness. Restricted to the **stable regime** `a∈[0.25,0.6]` (above ~0.7 the
effector–virus system limit-cycles; baseline becomes undefined). Realized baseline
pressure `k·E0` spans 0 → 1.7 across the range, monotone and at its predicted
equilibrium (verified).

## Answer: NO clean rescue — and the feedback cuts *against* the therapy

**1. Chronic (late) TIP — feedback is irrelevant once immunity is established.**
The rescue map (dynamic benefit − static-matched benefit) is **≈0 everywhere
`k·E0 ≳ 0.6`** (`a ≳ 0.45`): max late-TIP benefit there is **0.02 log**. The TIP
simply cannot invade against an established moderate response (R0_TIP < 1), so the
feedback never engages. **de Boer's pessimism is robust to adding the feedback.**

**2. Where the TIP *can* invade (low baseline immunity, high ψ), the feedback is
double-edged and unstable.** The rescue map there is a noisy mix of red (+3.5 log)
and blue (−3.5 log): the coupled TIP–virus–immune system tends to **limit-cycle**
rather than settle, so it is not clean sterilizing control — and endpoint metrics
in that corner are cycle snapshots, not stable setpoints.

**3. The deepest finding — early TIP sabotages protective immunity (timing.png,
right).** The intuitive fix "give the TIP early, before immunity matures" backfires:
co-administered at acute infection the TIP blunts antigen so effectively that
**adaptive immunity never develops (`k·E` stays ≈ 0)**, and WT settles into
**sustained oscillations between ~10³ and ~10⁶**, not control. The same TIP given
late (chronic) does nothing (immunity already up, TIP can't start). So the feedback
is strong — strong enough to **trade established immune control for TIP-driven
oscillatory viremia**. "Give it early" is not a free win; it risks knee-capping the
very response that would otherwise help.

## Verdict

This lands **closer to de Boer than to Pitchai**. Adding the realistic feedback does
**not** rescue the TIP in the regime that matters (established immunity); it confirms
the dead zone *and* surfaces a new failure mode (immune blunting + oscillation) that
neither the static model nor the simple "feedback helps" intuition predicted. The
honest one-line answer to the open question: **the feedback exists and is potent, but
its dominant effect is to couple TIP and immunity into oscillation / immune evasion,
not to open a clean therapeutic window.**

## Caveats (these bound the claim)

- **Minimal immune model.** No CD8 memory, exhaustion, or regulatory damping — all of
  which would temper the predator–prey oscillations. The oscillations are likely
  **exaggerated** by the simplest possible effector ODE; whether they survive a more
  realistic immune model is the first thing to check.
- **Oscillatory-regime metrics are unreliable.** In the limit-cycling corner I report
  *dynamics* (oscillation, `k·E≈0`), not point log-reductions; the jaggedness in
  timing.png (left) is cycle-phase sampling at t=900, not signal.
- **Parameterization, not calibration.** Absolute thresholds shift with `k, K_E, d_E,
  ρ, ψ`; the qualitative conclusions (no chronic rescue; early-TIP immune evasion) are
  the robust part.
- Carriers `I_t` spared by immunity; TIP entry `bt=b` — both conservative *toward* the
  TIP, so the negative result is not from stacking the deck against it.

## Reframed next question (P1.2)

The open question is no longer "does the feedback rescue the TIP" (it doesn't, cleanly)
but: **does a more realistic immune response (memory + exhaustion) damp the oscillations
into an immune-compatible controlled state — and is there a TIP design/timing that
achieves control *without* suppressing protective immunity?** Concretely:
1. Add effector memory + exhaustion terms; re-run timing — do oscillations damp to a
   stable low-load controlled equilibrium?
2. Use **limit-cycle time-averaged** viral load as the metric (not t=900 snapshots).
3. Search `(dose, timing, ψ)` for a regime that lowers WT *and* preserves `E` —
   "immune-compatible TIP." If none exists, that is a sharp design constraint:
   TIPs and CTL-based functional cure (a prominent functional-cure approach) may be
   **antagonistic**, which would be a genuinely important negative result.
